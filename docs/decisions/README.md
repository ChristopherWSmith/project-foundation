# Architecture Decision Records

One file per decision, numbered, never rewritten. When a decision changes, a new ADR supersedes the old one, so the reasoning trail survives and agents stop reopening settled questions.

**Write one when** you choose between real alternatives that someone (or an agent) might later question: a framework, a data-model shape, a vendor, a pattern you'll repeat, a pricing or grandfathering policy.
**Don't write one for** choices with no real alternative, or anything easily reversed.

Create one with `/adr <decision>`, or copy `0000-template.md`.
